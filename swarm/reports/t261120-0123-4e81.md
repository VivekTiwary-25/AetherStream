Added web/public/glorious/truck.png (154x128 transparent; cut from the truck at mockup box 1370,325-1485,425 using rembg u2net, then removed faint alpha and kept only the largest blob) and web/public/glorious/truck-photo.jpg (135x136, q85, box 449,260-584,396 with the rounded corners cut off).
The script is design/ui-glorious/sprites/cut_sprites.py and the notes are in notes.md. rembg does not install on Python 3.15, so I ran it in a Python 3.12 venv (uv) outside the repo.
I checked by compositing onto #f3efe6 and #9bd3a0 (sprites/preview-*.png) and looking at 4x zooms. Edges are clean, with no halo, leftover background or glow ring. isnet-general-use was worse (grey haze), so I used u2net.
Verdict: GOOD for cleanliness, but the truck is only 75 px tall in the mockup, so truck.png is upscaled about 1.7x and looks a little soft. I skipped truck@2x.png because it would need a 3.4x upscale.
