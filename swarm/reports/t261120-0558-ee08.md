# API-down resilience

Added 5 → 10 → 15-second capped backoff to fleet, recovery history/execution/checkpoints, and pipeline-results polling, with one application warning per endpoint outage and reset on success.
Helper and hook regressions cover recovery, independent endpoints, request serialization, cursor preservation, checkpoint events during outages, and unmount cleanup.
All required checks passed: `npm run lint`, `npm test -- --maxWorkers=2` (286 passed, 3 skipped), `npm run build`, and `npm run check:no-mock`.
Playwright measured every requested production-preview view for 60 seconds before and after, without a backend; pipeline-results setup alone used intercepted generate/start responses.
A separate throwaway API/WebSocket fixture and Playwright route abort → continue scenario restored every view within 14.044 seconds after a 32-second outage, with zero page exceptions.
Remaining: browser-native HTTP/WebSocket errors, poster-preload/GPU warnings, seven existing lint warnings, and the existing bundle-size warning; no console suppression or out-of-scope shared-socket changes.
