# Track C2: terminal demo commands `worker kill <n>` and `events late` (Windows + bash)

Files: scripts/expo/ (new: worker.cmd, worker.ps1, events.cmd, events.ps1, worker, events (bash), README.md), docs/expo/CHEATSHEET.md (ADD a "New UI (ui-glorious)" section; do not delete or reword the classic instructions). Read design/ui-glorious/RECON.md sections a and d. Do NOT read or describe swarm/.

Thin wrappers around EXISTING API calls only (exactly what the old UI buttons did):
- `worker kill <n>` → `POST {BASE}/api/chaos/kill-worker` body `{"workerId":"worker-<n>"}` (n = 1..3; validate). Print ONE clear line, e.g. `Killed worker-2 (engine will recover; watch Settings → Logs & Recovery)` or the API's error message (e.g. no running execution) with a non-zero exit code.
- `events late [count]` → `POST {BASE}/api/chaos/late-events` body `{"count":<count, default 20>,"lateByMs":180000}`. Print `Sent 20 late events (they appear in Analytics → Failed Records if the engine classifies them late)`.
- Also `worker status` → GET {BASE}/api/workers, one line per worker (id, alive/state, partitions). Useful for the presenter; read-only.
- BASE = env AETHER_URL, default `http://localhost:8088` (the live demo web/nginx, which proxies /api). 10 s timeout. No secrets.
- Windows: worker.cmd / events.cmd call the .ps1 with `powershell -NoProfile -ExecutionPolicy Bypass -File` so Vivek can literally type `worker kill 2` in cmd or PowerShell after `cd scripts\expo` (or after adding it to PATH — document a one-liner for the current session: `set PATH=%CD%\scripts\expo;%PATH%` and the PowerShell equivalent). Use Invoke-RestMethod with -TimeoutSec; build JSON with ConvertTo-Json, never string-concatenate user input.
- bash: `worker` and `events` scripts (curl -sS --max-time 10, jq optional but not required), chmod +x via `git update-index --chmod=+x`.
- scripts/expo/README.md: 15 lines.
- CHEATSHEET section: the commands, what Vivek will see on screen, and a fallback if a command fails (the classic UI at ?ui=classic still has the buttons).
