Files: web/vitest.config.* or web/vite.config.* (test section), web/src/test setup file(s) (whatever setupFiles the config names), web/package.json (scripts only). No app code changes.
Rules: Do not read, explain or modify swarm/ code (writing your own task report file is the one exception). Never stop, restart or change the swarm. Every command needs a timeout; nothing may wait for input. Never touch port 8088 or the live demo on vivek-pc, never start Docker. No mock, fake or placeholder data. Small task (10-20 min).

On this PC (Node v26) `npx vitest run` in web/ fails 34 tests with "Cannot read properties of undefined (reading 'clear'/'setItem')" on localStorage (see design/ui-glorious/proof/classic/CHECK2.md). Cause: Node's own experimental webstorage global shadows jsdom's localStorage. Passing NODE_OPTIONS=--no-experimental-webstorage makes them pass. Fix it in the repo so plain `npx vitest run` passes on Node 20, 22 and 26: e.g. vitest poolOptions execArgv ['--no-experimental-webstorage'] guarded so older Node does not reject the flag, or a setup-file fallback that installs a working in-memory Storage on window when window.localStorage is missing/broken. Prove: full `npx vitest run` from web/ (report pass/fail/skip counts before and after) and `npm run build`. End with a short report.
