# T164: Kill-worker reliability - 20 kills in a row, every recovery fast  [expo safety]

Lane 8. The kill-worker moment is the centre of the demo; it must work every time. Write infra/scripts/kill-repeat.sh: against a
running stack (API base URL arg, default http://localhost:18080), 20 times: pick the next worker round-robin, press the same
API the UI "Kill worker" button uses (contract 04 chaos kill), measure time to execution RUNNING in a newer generation and time
until the killed worker rejoins and owns partitions again, then wait for one completed checkpoint. After all 20: run
POST /api/compare (must be N/N, N > 0). Print a table (kill #, worker, failover s, rejoin s) plus min/median/p95/max, and fail
if any failover > 15 s, any rejoin > 60 s, or compare mismatches. Add a workflow .github/workflows/ci-kill-repeat.yml
(workflow_dispatch + push to task/** when these files change) that starts the stack like ci-e2e does, starts the demo pipeline
(reuse demo-ready.sh), runs the script, and writes the table to the step summary. Put the CI numbers in docs/expo/kill-repeat.md.
