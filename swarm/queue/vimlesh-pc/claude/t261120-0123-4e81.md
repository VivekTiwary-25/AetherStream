# Track A0: cut the truck marker sprite and the card photo from the mockup

Files: web/public/glorious/truck.png (new), web/public/glorious/truck-photo.jpg (new), design/ui-glorious/sprites/ (new: script + notes). Input: design/ui-glorious/liveworld-mockup.png (1672x941).

1. Truck marker sprite: the mockup shows several identical white box trucks at a 3/4 angle (cab facing left-front). The cleanest isolated one is around x 1380-1475, y 335-420 (right of "Mysuru Palace"), others around x 900-1000, y 715-800 and x 420-520, y 660-745. Crop one generously, then remove the background automatically: `python -m pip install --user "rembg[cpu]" pillow` and use rembg (u2net or isnet-general-use). Remove the green/orange ground glow ring under the wheels (we draw our own glow in CSS) — crop above the ring or erase it. Output a tight-cropped transparent PNG, height 128 px (keep aspect), trimmed of empty margins: web/public/glorious/truck.png. Also save a 2x version truck@2x.png if the source resolution allows (do not upscale beyond the source).
2. Card photo: the info card at about x 444-588, y 255-400 contains a photo of a truck on a road. Crop just the photo (rounded corners are fine to square off), save as web/public/glorious/truck-photo.jpg (quality 85).
3. Save the exact script you used as design/ui-glorious/sprites/cut_sprites.py (paths relative to repo root) so it can be re-run, plus a 5-line notes.md (model used, crop boxes).
4. Check quality: open the PNG on a light map-like background (e.g. composite onto #f3efe6 and onto #9bd3a0 and save previews to design/ui-glorious/sprites/preview-*.png). No leftover halo/background blobs, edges clean, no glow ring. If rembg's result has visible artefacts, try another rembg model or alpha-matting before giving up.

Report: which crop and model, final pixel sizes, and an honest verdict: GOOD or POOR (if POOR, say what is wrong so the boss can ask Vivek for a transparent PNG).
