# T02: Web app scaffold (Vite + React + TypeScript) with design system and app shell

Lane 6 (web/app). Create the web app skeleton the city and panels will live in.

Files (create only these, all under web/ except the workflow):
- web/package.json, web/package-lock.json (generate it if you can run npm; if you cannot, omit it and make CI use `npm install` instead of `npm ci` — say which in your result)
- web/tsconfig.json, web/tsconfig.node.json (if needed), web/vite.config.ts, web/eslint.config.js, web/index.html
- web/src/main.tsx, web/src/App.tsx
- web/src/styles/tokens.css, web/src/styles/global.css
- web/src/app/shell/AppShell.tsx, web/src/app/shell/Footer.tsx, web/src/app/shell/MockBadge.tsx
- web/src/app/ui/GlassPanel.tsx, web/src/app/ui/ClayButton.tsx, web/src/app/ui/StatusPill.tsx
- web/src/city/CityPlaceholder.tsx (a simple placeholder; lane 5 replaces it)
- web/src/App.test.tsx (Vitest + @testing-library/react)
- web/.gitignore
- .github/workflows/ci-web.yml

What to build:
1. Vite 7 + React 19 + TypeScript 5.9 (strict). Scripts: `dev`, `build` (tsc -b && vite build), `lint` (eslint), `test` (vitest run), `preview`. Dev server proxies `/api` and `/ws` (ws: true) to `http://localhost:18080`.
2. Design system in tokens.css (CSS custom properties): dark navy/charcoal background (#0b1020-ish to #121826), restrained luminous accents (cyan #5eead4-ish for data flow, amber for backpressure, red for failure, green for healthy, violet for checkpoints), glass surface (translucent fill, backdrop-filter blur, 1px hairline border, soft shadow), clay button (soft rounded, inner highlight + outer soft shadow, pressed state), radius scale, spacing scale, type scale (Inter/system-ui), readable contrast (text >= 4.5:1 on panels). Respect `prefers-reduced-motion`. Motion only for state changes/hover/press (150–250 ms).
3. AppShell: full-viewport layout. The city canvas fills the background (CityPlaceholder for now: a dark gradient with a subtle grid). Floating over it, a bento grid region on the right/bottom for panels (empty named slots: "windows", "deliveries", "alerts", "deadLetters", "workers", "chaos", "compare"), a top-left title "AetherStream" with a StatusPill, and a Footer.
4. GlassPanel(title, children, status?), ClayButton(variant primary|danger|ghost, onClick, disabled, children), StatusPill(state: running|backpressured|checkpointing|recovering|paused|failed|healthy) — always text label plus colour (accessibility rule from handoff.md section 11).
5. Footer: fetches GET /api/version (contract 04 will define `{ "commit": string, "builtAt": string }`); shows "Deployed version: <first 7 chars of commit>" or "version unknown" on error. Also shows MockBadge.
6. MockBadge: renders a clear amber "MOCK DATA" badge only when `import.meta.env.VITE_USE_MOCK === '1'`; renders nothing otherwise.
7. App.test.tsx: renders App; asserts the title text is present; asserts MockBadge is NOT shown when VITE_USE_MOCK is unset; Footer shows "version unknown" when fetch fails (mock fetch).
8. .github/workflows/ci-web.yml: on push to main and task/**, pull_request to main; ubuntu-latest, Node 22, working-directory web: install, `npm run lint`, `npm run test`, `npm run build`. Upload web/dist as an artifact.

Acceptance check: `ci-web` workflow green on your task branch (lint, tests, build all pass).
