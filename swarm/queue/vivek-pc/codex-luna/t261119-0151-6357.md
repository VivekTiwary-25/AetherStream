# T42: Checkpoint + recovery timeline panel (explains fault tolerance visually)

Lane 6 (web/app). A new glass panel that tells the fault-tolerance story live: checkpoints completing, a worker dying,
recovery from checkpoint #N with a new generation, and back to running. Uses contract 04:
`GET /api/executions/current`, `GET /api/executions/{id}/checkpoints?limit=20`, WebSocket `execution` and `workers` messages
via the shared hook in web/src/api/ws.ts and types in web/src/api/types.ts (import them; do not edit them).

Files (create only these):
- web/src/app/timeline/** (CheckpointTimeline.tsx, timelineModel.ts with pure functions, index.ts exporting `CheckpointTimeline`)
- web/src/app/timeline/__tests__/**
Do NOT edit any other file (a later integration task mounts the panel in the shell).

Design: a horizontal timeline (last ~2 minutes, auto-scrolling): small violet ticks for COMPLETED checkpoints (#id, duration
ms on hover), grey ticks for ABORTED, a red marker "worker-2 lost" (WORKER_DEAD), an amber band while RECOVERING labelled
"Recovering from checkpoint #N (generation G -> G+1)", a green marker "Recovered in X.X s". Below: a compact row
"Generation 3 · Last checkpoint #42 (84 ms) · Restored from #39". Text + colour for every state; aria-live for new events;
reduced-motion aware. Poll checkpoints every 5 s while visible; merge with WS events. Use GlassPanel from web/src/app/ui.

Tests: timelineModel builds the right segments from a sequence of execution events + checkpoint rows (recovery band start/end,
recovered duration); component renders "Recovering from checkpoint #12".

Acceptance check: `ci-web` green on your branch.
