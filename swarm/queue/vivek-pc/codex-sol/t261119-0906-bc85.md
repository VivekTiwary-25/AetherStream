# T165: Public-link watchdog for the expo (quick tunnel survives restarts)  [expo safety]

Lane 7. vivek-pc exposes the demo through a Cloudflare quick tunnel: Scheduled Task "AetherStream-Tunnel" runs
C:/Users/Arena/bin/aether-tunnel.cmd, the current https://<words>.trycloudflare.com URL is printed into
C:/Users/Arena/aether-tunnel.log and changes on every restart. Write infra/deploy/tunnel-watchdog.ps1 (PowerShell 5.1): every
60 s read the newest URL from the log, GET <url>/api/version (timeout 10 s); after 3 failures in a row restart the tunnel task
(Stop/Start-ScheduledTask "AetherStream-Tunnel"), wait for the new URL, and write it to C:/Users/Arena/aether-public-url.txt and
to a tiny local HTML page C:/Users/Arena/aether-link.html with the URL as a big link and a QR code (generate the QR as an inline
SVG in PowerShell, no internet, no external module; a minimal QR encoder is fine, or skip QR and show the URL in 64px text if a
correct encoder is too big). Plus infra/deploy/register-tunnel-watchdog.ps1 (Scheduled Task at logon, -Unregister switch).
Add a -DryRun mode that only prints what it would do. Do not run or register anything on vivek-pc.

Files (edit only these): infra/deploy/tunnel-watchdog.ps1 (new), infra/deploy/register-tunnel-watchdog.ps1 (new),
docs/runbook.md (one short "Public link watchdog" section).

Acceptance check: ci-mock green on your branch; paste the -DryRun output.
