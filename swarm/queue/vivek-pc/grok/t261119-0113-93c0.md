Contents (plain, simple English; use Mermaid diagrams, GitHub renders them):
1. One-paragraph summary and a component diagram (browser city + panels + editor -> nginx -> control-api -> coordinator,
   workers x3, simulator -> Kafka (6 partitions) -> workers -> Postgres; workers/coordinator -> MinIO checkpoints).
2. Control plane vs data plane vs recovery coordination (table of components and responsibilities, matching contract 00 modules).
3. Data model: event envelope, pipeline JSON, execution plan (short examples).
4. Operator semantics: per-partition watermarks, tumbling windows, late events, dedup, rule streaks; why per-partition
   watermarks make the result independent of worker placement; one sequence diagram of a record flowing through.
5. Worker runtime: the 3-stage bounded pipeline (source -> operator -> sink), backpressure.
6. Checkpoint protocol: aligned barriers (Chandy-Lamport style) with a sequence diagram (coordinator trigger -> source
   records offsets + barrier -> operator snapshot -> sink flush + upload -> ack -> manifest -> COMPLETED); why the manifest is
   written only after all acks; checkpoint 0.
7. Failure detection and recovery: heartbeat timeout, generation bump (fencing token), CANCEL/ASSIGN, restore + replay from
   saved offsets; fenced sink transaction (SELECT ... FOR SHARE); a state diagram RUNNING -> RECOVERING -> RUNNING.
8. Processing guarantees (contract 03 section 5, word for word in meaning) and how "Compare with reference" checks them.
9. Deployment and CI/CD: workflows (contract 00 CI table), images, GHCR by commit SHA, self-hosted runner deploy, smoke test
   of /api/version == commit SHA; a pipeline diagram (push -> CI -> publish -> deploy -> smoke).
10. Tech stack table with pinned versions (contract 00) and "Design decisions and trade-offs" (HTTP/JSON heartbeat-piggybacked
    commands instead of gRPC, single coordinator baseline, no repartitioning in v1, Spring Boot 3.5 for Jackson 2, community
    MinIO image) and "Limitations / future work" (coordinator HA, rescaling, savepoints, Kubernetes/Terraform).
