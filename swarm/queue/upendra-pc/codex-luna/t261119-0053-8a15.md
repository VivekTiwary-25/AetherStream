# T07: control-api core (Spring Boot): health/ready/version, executions, workers, results, chaos + simulator proxies

Lane 3 (control-api). Implement the REST endpoints of contract 04 EXCEPT the pipeline endpoints (`/api/pipelines/**`)
and `/api/compare` and the WebSocket (later tasks do those). Spring Boot 4.1 (spring-boot-starter-web, jdbc, actuator are
already in control-api/build.gradle.kts; do not edit it - if you need something else, say so in your result).

Files (create/edit only these):
- control-api/src/main/java/io/aetherstream/api/** (ControlApiApplication.java already exists; add controllers, clients, repositories)
- control-api/src/main/resources/application.yml
- control-api/src/test/java/io/aetherstream/api/**

What to build:
1. application.yml: port 8080; datasource from env PG_URL/PG_USER/PG_PASSWORD (defaults from contract 00);
   `spring.sql.init.mode=never` (schema comes from infra/db/schema.sql); actuator health exposed but our own /api/health is the contract.
2. `GET /api/health`, `GET /api/ready` (checks postgres `SELECT 1`, kafka AdminClient describeCluster with 2 s timeout,
   coordinator GET /coord/health, simulator GET /health; 503 when any DOWN), `GET /api/version` (env GIT_SHA, BUILT_AT).
3. `CoordinatorClient` and `SimulatorClient` using java.net.http.HttpClient (2 s connect / 5 s request timeouts) with base URLs
   from env COORDINATOR_URL and SIMULATOR_URL. Proxy endpoints: `/api/chaos/*`, `/api/simulator/*`, `/api/workers`
   (from /coord/state), `GET /api/executions/current`, `GET /api/executions/{id}`, `POST /api/executions/{id}/stop`,
   `GET /api/executions/{id}/checkpoints` (read the checkpoints table directly). When the upstream is down return 502
   `{"error":"UPSTREAM_DOWN","message":"coordinator is not reachable"}`.
4. Results endpoints reading Postgres with JdbcTemplate: `/api/results/windows`, `/api/results/alerts`,
   `/api/results/dead-letters`, `/api/results/summary` (current execution = the newest row in executions with state not STOPPED,
   else newest). `deliveriesLastMinute` = sum of `values->>'deliveries'` of rows with sink_id 'delSink' in the newest
   complete window; `avgSpeedLastMinute` = average of `values->>'avgSpeedKmh'` for sink 'speedSink' in the newest window.
   `eventsPerSec` = sum of recordsPerSec of workers from the coordinator (0 if unreachable).
5. Error JSON `{"error","message"}` everywhere (a @RestControllerAdvice). CORS: allow all origins for /api/** (dev).
6. Tests: WebMvc-style tests with mocked CoordinatorClient/SimulatorClient/repositories for version, health, a chaos proxy,
   upstream-down 502, and summary JSON shape. No Docker needed for these tests.

Acceptance check: `ci-java` workflow green on your branch.
