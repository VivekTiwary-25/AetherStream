Problem: trucks move jaggedly and sit beside the yellow roads instead of on them. Causes in the code, fix all four:
1. animate() adds a per-truck perpendicular offset `(index - 2.5) * 18` px. REMOVE it. Each truck already has its own route, so the marker must sit exactly on the road line.
2. That offset is perpendicular to the CURRENT segment (segments are 23-45 m), so it flips at every bend. Removing it (1) fixes most of the jitter; make sure no other per-segment offset remains.
3. placeMarker() jumps a marker 80 px up when two markers overlap. Replace the instant jump: either shift only the LABEL (never the truck itself) or use a smoothed/eased offset that changes gradually over several frames. Prefer: the truck stays on the road, only the label moves.
4. facingLeft() uses the current tiny segment, so the sprite flips on zigzags. Decide facing from the direction to the point ~100 m ahead along the route, with hysteresis (e.g. only flip when the horizontal component clearly changes sign beyond a small threshold), so it does not flicker.

Put the pure maths (look-ahead point along a route, facing with hysteresis, eased label offset) in mapLogic.ts as small exported functions, and test them in mapLogic.test.ts: a marker position lies on the route polyline (no offset); facing does not flip on a short zigzag but does flip on a real U-turn; the overlap offset changes gradually, not in one jump.
