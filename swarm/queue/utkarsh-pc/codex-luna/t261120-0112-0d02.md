1. Write the three PowerShell scripts in scripts/preview/ (committed with this task):
   - preview-up.ps1: if missing, `git clone --branch ui-glorious https://github.com/VivekTiwary-25/AetherStream.git C:\aether-preview` (else fetch + `git reset --hard origin/ui-glorious` there).
