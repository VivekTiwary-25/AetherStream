# Strip audio from the home loop video and make a poster frame

Files: design/ui-glorious/home-loop.mp4 (input and output), design/ui-glorious/home-poster.jpg (new)

This branch is `ui-glorious`. Do exactly this, nothing else:

1. Find ffmpeg (`ffmpeg -version`). If it is missing, run `python -m pip install --user imageio-ffmpeg`
   and use the binary from `python -c "import imageio_ffmpeg;print(imageio_ffmpeg.get_ffmpeg_exe())"`.
2. Remove the audio track WITHOUT re-encoding video:
   `ffmpeg -y -i design/ui-glorious/home-loop.mp4 -map 0:v:0 -c:v copy -an -movflags +faststart design/ui-glorious/_tmp.mp4`
   then replace home-loop.mp4 with _tmp.mp4 (delete _tmp.mp4 afterwards).
3. Make a poster of the first frame: `ffmpeg -y -i design/ui-glorious/home-loop.mp4 -frames:v 1 -q:v 3 design/ui-glorious/home-poster.jpg`
4. Check with ffprobe (or ffmpeg -i) that home-loop.mp4 now has one h264 video stream (1264x720) and NO audio stream, and that home-poster.jpg exists.

Acceptance: home-loop.mp4 has no audio stream, same resolution and duration (~6.0 s); home-poster.jpg exists. In your report, give the stream list and file sizes.
