# T89: Web test coverage report + threshold in CI

Lane 6 (web). Add Vitest coverage (v8) to the web app and publish it in CI.

Files (edit/create only these): web/package.json + web/package-lock.json (add @vitest/coverage-v8 matching the installed
vitest major), web/vite.config.ts (test.coverage: provider v8, reporters text-summary + html + json-summary, include
src/**, exclude tests/mock), .github/workflows/ci-web.yml (run `npm run test -- --coverage`, upload web/coverage as an
artifact, write the text summary to $GITHUB_STEP_SUMMARY).

Set thresholds at the CURRENT measured level minus 2 points (lines/branches/functions/statements) so CI fails on a drop -
measure first in CI, then set. Do not edit app source or tests.

Acceptance check: `ci-web` green on your branch with the coverage summary in the step summary (paste it in your result).

## Rules
- Do not change anything in swarm/ (except your own report file if the swarm asks you to write one).
- Only the listed files. If you are on vivek-pc: do NOT start Docker containers there.
